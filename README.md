# Climate Change Data Analysis

## Overview
This project investigates greenhouse gas emissions using statistical modeling and visualization tools in R. The goal of this project is to find relationships between climate-related variables by utilizing exploratory data analysis and multiple linear regression methods.

This project was carried out as part of PSTAT 100: Data Science Concepts and Analysis course from the University of California, Santa Barbara.

## Goals
- Investigate greenhouse gas emissions.
- Visualize relationships between variables.
- Build and assess multiple linear regressions.
- Interpret statistical results and check model assumptions.

## Methods 
The analysis consists of:
- Data cleaning and preparation
- Exploratory Data Analysis (EDA)
- Data visualization with ggplot2
- Correlation analysis
- Multiple Linear Regression
- Regression diagnostics

## Tools & Technologies
- R
- ggplot2
- dplyr
- tidyr
- readr
- knitr

## Results
Using statistical modeling and visualization techniques, the relationships among greenhouse gas emission variables were found. Diagnostics for regression were conducted to test the regression model assumptions and results were discussed in a technical report.
