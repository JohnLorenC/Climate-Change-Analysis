# Climate Change Data Analysis

## Overview
This project analyzes greenhouse gas emissions using R to investigate relationships between environmental variables through exploratory data analysis and statistical modeling.

## Objectives
- Explore trends in greenhouse gas emissions.
- Identify relationships between variables.
- Build and evaluate multiple linear regression models.

## Methods
- Data cleaning
- Exploratory Data Analysis (EDA)
- Data visualization with ggplot2
- Correlation analysis
- Multiple Linear Regression
- Regression diagnostics

## Tools
- R
- ggplot2
- dplyr
- tidyr
- readr
